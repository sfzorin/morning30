# Иллюстрации упражнений

Эталон каждого персонажа показывает его в полный рост спереди, со спины и в три четверти. Для следующей иллюстрации используйте отдельный лист нужного персонажа.

| Персонаж | Лист с тремя ракурсами | Код в приложении |
| --- | --- | --- |
| Женщина | [woman.png](../character-references/turnarounds/woman.png) | `f` |
| Мужчина | [man.png](../character-references/turnarounds/man.png) | `m` |
| Девочка | [girl.png](../character-references/turnarounds/girl.png) | `g` |
| Мальчик | [boy.png](../character-references/turnarounds/boy.png) | `b` |

Для каждого упражнения записаны его идентификатор, инструкция из библиотеки и положение тела в каждом кадре. Удержанию соответствует один кадр. В упражнениях NK07 и NK08 показаны две разные удерживаемые позиции. [Упражнения и фазы](exercises.json)

Приложение читает готовые изображения из каталогов `ID/персонаж/`. Файл `still.webp` служит обложкой. У движений есть также горизонтальная полоса из двух или трёх квадратов по 512 пикселей. Поле `cover` указывает номер кадра для обложки, начиная с единицы. [Изображения](../../assets/static/exercise-art/v1/) · [Фазы и порядок воспроизведения](../../assets/static/exercise-art/v1/motions.json) · [Упражнения с общей иллюстрацией](../../assets/static/exercise-art/v1/shared-movements.json)

Для повторной генерации передайте ImageGen лист персонажа и описание фаз. Готовую иллюстрацию можно использовать как образец ракурса и позы. Для меню выбора берётся левый ракурс утверждённого листа по прямоугольнику `112 0 384 1024` и экспортируется в WebP размером 120 × 320. [Параметры генерации](generation.json) · [Картинки для меню](../../assets/static/characters/)

Упаковщик принимает PNG одной демонстрации, число кадров, режим воспроизведения и каталог результата. Для L01 передайте файл выравнивания через `--registration`, чтобы опорная стопа оставалась на месте. [Упаковщик](../../scripts/pack_exercise_art.swift) · [Поправки для L01](L01-registration.json)
